# ربات تلگرامی پخش فیلم و سریال

این یک ربات تلگرامی کامل برای پخش فیلم و سریال با امکانات پیشرفته است که شامل بخش ادمین و کاربر می‌شود.

## ویژگی‌های ربات

### بخش ادمین:
- امکان انتشار فیلم و سریال جدید
- مدیریت کاور و توضیحات فیلم‌ها
- تنظیم چنل‌های مختلف (بایگانی، اصلی، پشتیبان، اعلانات)
- مدیریت چنل‌های عضویت اجباری
- تنظیم کاور پیش‌فرض
- امکان افزودن ادمین‌های جدید با لینک دعوت

### بخش کاربر:
- دریافت فیلم‌های تصادفی
- دسترسی به فیلم‌ها پس از عضویت در چنل‌های اجباری
- امکان دریافت فیلم‌ها با کلیک روی دکمه دریافت
- حذف خودکار فیلم‌ها پس از 30 ثانیه برای امنیت

## نحوه نصب و اجرا

1. **آماده‌سازی سرور**:
   - سرور با پشتیبانی از PHP 7.4 یا بالاتر
   - cURL برای ارسال درخواست‌های HTTP

2. **قرار دادن فایل‌ها**:
   - فایل `telegram_media_bot.php` را در پوشه مورد نظر قرار دهید
   - اطمینان حاصل کنید که دسترسی نوشتن برای فایل‌های JSON فراهم باشد

3. **تنظیم وبهوک تلگرام**:
   - به @BotFather بروید و ربات خود را ایجاد کنید
   - وبهوک را روی آدرس فایل `telegram_media_bot.php` تنظیم کنید
   - مثال: `https://yourdomain.com/telegram_media_bot.php`

4. **پنل مدیریت**:
   - فایل `admin_panel.php` را برای دسترسی گرافیکی به ربات استفاده کنید
   - این پنل تحت وب امکان مدیریت تمامی بخش‌های ربات را فراهم می‌کند

## ساختار فایل‌ها

- `telegram_media_bot.php`: هسته اصلی ربات تلگرام
- `admin_panel.php`: پنل مدیریت تحت وب
- `media.json`: ذخیره فیلم‌ها و سریال‌ها
- `admins.json`: ذخیره ادمین‌ها
- `users.json`: ذخیره کاربران
- `settings.json`: تنظیمات ربات
- `user_states.json`: وضعیت کاربران در فرآیند ارسال فیلم
- `scheduled_deletions.json`: زمان‌بندی حذف فیلم‌ها

## نحوه استفاده

### برای ادمین:
1. ربات را استارت کنید تا پنل ادمین نمایش داده شود
2. از دکمه "انتشار مدیای جدید" برای ارسال فیلم استفاده کنید
3. توضیحات و کاور فیلم را ارسال کنید
4. فیلم به صورت خودکار در چنل‌های تنظیم شده ارسال می‌شود

### برای کاربر:
1. ربات را استارت کنید
2. از دکمه "مدیای رندوم" برای دریافت فیلم تصادفی استفاده کنید
3. برای دریافت فیلم، در چنل‌های اجباری عضو شوید و دکمه "عضو شدم" را بزنید

## امنیت

- فیلم‌ها 30 ثانیه پس از ارسال حذف می‌شوند
- کاربران برای دریافت فیلم باید در چنل‌های مشخص شده عضو باشند
- امکان مدیریت ادمین‌ها تنها برای ادمین‌های اصلی فراهم است

## توجه

- این ربات به صورت تک‌فایلی طراحی شده است اما برای عملکرد کامل به فایل‌های JSON برای ذخیره داده‌ها نیاز دارد
- برای تغییر توکن یا آیدی ادمین‌ها، فایل `telegram_media_bot.php` را ویرایش کنید
